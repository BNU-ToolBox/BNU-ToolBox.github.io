快速开始

四步开始使用

建议先完成全局账号配置，再进入具体插件设置任务范围。

  1. 01

    下载并运行安装程序

    下载 Windows 安装包，按提示授予管理员权限并完成安装。

  2. 02

    配置全局账号

    在“全局设置”中填写北师大统一身份认证账号。校园网账号与统一身份认证账号分别配置，账号仅加密保存在本地。

  3. 03

    安装插件并设置范围

    在“插件管理”中安装所需插件，再选择课程、任务或认证方式；首次运行时留意必要的警告与确认提示。

  4. 04

    启动任务并查看进度

    启动插件后，可在详情页查看分线程进度、预计剩余时间与运行日志。

常见问题

安装与运行说明

Windows 显示“未知发布者”怎么办？

当前测试版安装包尚未进行代码签名。确认安装包来自本页面或官方 Releases 后，可选择“更多信息”并继续安装。

需要预先安装 Python 或 EdgeDriver 吗？

不需要。安装包已包含 Python 运行时；EdgeDriver 会根据本机 Edge 版本自动获取。

配置和缓存保存在哪里？

统一保存在 %LOCALAPPDATA%\BNU-ToolBox。卸载应用时默认保留这些数据。

是否适合直接用于关键任务？

0.1.0 是公开测试版本，建议先使用少量任务验证配置和运行结果，若运行稳定再启动大量任务。
